# Startup capture

`phone-startup.png` is an actual QEMU/KVM display capture at 15 seconds into
the recorded cold boot on 2026-10-18 UTC. It shows the installed Plymouth theme,
not a mockup. See capture-manifest.json for source context and SHA-256.

The public startup MP4 is a continuous 35-second OS-startup excerpt. The
14.6-second GIF shortens the idle transition. Both are published as release
assets under brand-kit-20261017. Full raw capture frames stay in ignored build/.
